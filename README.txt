how to play??

1. Two players each select a character to play.

2. Player 1 uses the W, A, D keys to jump and move left or right, and the T, G, H, J keys to perform attacks and skills.
- G key = Basic Attack
- H key = Dash
- (Other skills will be implemented after Playtest 1.)

3. Player 2 uses the Arrow keys to jump and move left or right, and the 4, 1, 2, 3 keys to perform attacks and skills.
- Key 1 = Basic Attack
- Key 2 = Dash
- (Other skills will be implemented after Playtest 1.)

4. Players win by reducing the opponent’s HP to zero using basic attacks and skills.

5. The game is played in a best-of-three format; the first player to win two rounds is the overall winner.
